# Cognitive Bias Prediction Platform

IB Computer Science Extended Essay — research tool for
"To what extent can machine learning models predict human decision-making in cognitive bias tasks?"

---

## Repository structure

```
cogbias/
  app.py                     Streamlit entrypoint; routes between survey and admin
  survey.py                  Participant survey (consent → instructions → 30 trials → done)
  scenarios.py               30 scenario templates + per-participant parametric generator
  storage.py                 Supabase insert / fetch / export helpers
  pipeline.py                Standalone ML pipeline (importable + runnable as a script)
  admin.py                   Password-gated analysis dashboard
  config.py                  Global constants, feature spec, encodings, RNG seed
  requirements.txt
  .streamlit/
    secrets.toml.example     Copy → secrets.toml and fill in your credentials
  sample_data/
    make_synthetic.py        Generate synthetic data for pipeline testing
    synthetic_responses.csv  Auto-generated by make_synthetic.py
```

## Setup

### 1 — Create a Supabase project and run the DDL

1. Go to [supabase.com](https://supabase.com) → New project (free tier is sufficient).
2. Open **SQL Editor** and run the following DDL exactly once:

```sql
CREATE TABLE responses (
    id                   BIGSERIAL PRIMARY KEY,
    participant_id       UUID        NOT NULL,
    participant_seed     INTEGER     NOT NULL,
    scenario_template_id TEXT        NOT NULL,
    trial_index          SMALLINT    NOT NULL,
    bias_type            SMALLINT    NOT NULL,
    frame                SMALLINT    NOT NULL,
    expected_value_ratio REAL        NOT NULL,
    anchor_value         REAL        NOT NULL,
    previous_choice      SMALLINT    NOT NULL,
    is_first_trial       SMALLINT    NOT NULL,
    reaction_time_ms     INTEGER     NOT NULL,
    choice               SMALLINT    NOT NULL,
    created_at           TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_responses_participant ON responses (participant_id);
```

3. Under **Project Settings → API**, copy:
   - **Project URL** → `SUPABASE_URL`
   - **anon / public** key → `SUPABASE_KEY`

### 2 — Fill in secrets

```bash
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
```

Edit `.streamlit/secrets.toml` and set `SUPABASE_URL`, `SUPABASE_KEY`, and `ADMIN_PASSWORD`.

### 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### 4 — Run locally

```bash
streamlit run app.py
```

The survey is at `http://localhost:8501` (the default Survey page).
The admin dashboard is at the same URL — open the sidebar and select **Admin**.

### 5 — Test the pipeline before real data (recommended)

```bash
python sample_data/make_synthetic.py 40 sample_data/synthetic_responses.csv
python pipeline.py sample_data/synthetic_responses.csv sample_data/
```

This generates 40 synthetic participants, runs the full CV pipeline, prints all
metric tables, and saves the four figures to `sample_data/`.

## Deployment (Streamlit Community Cloud)

1. Push the `cogbias/` folder to a GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app** → select your repo.
3. Set **Main file path** to `app.py`.
4. In **Advanced settings → Secrets**, paste the contents of your `secrets.toml`.
5. Deploy. Share the survey URL with participants.

---

## Collecting data

1. Share the Streamlit app URL with IB Diploma participants.
2. Participants complete the 30-question survey (≈15–20 min) in one sitting.
3. Each session auto-saves to Supabase on the final screen.

---

## Running the analysis

1. Open the deployed app → sidebar → **Admin** → enter your admin password.
2. Click **Pull latest data from Supabase** (or upload a local CSV for testing).
3. Click **Run full analysis**.
4. Download tables/figures from the tabs that appear:
   - **§4.1** — overall accuracy, precision, recall, F1 for both models + baselines
   - **§4.2** — per-bias-type metrics + grouped bar chart (downloadable PNG)
   - **§5.2** — LR feature coefficients (table + bar chart)
   - **Confusion Matrices** — aggregated across CV folds (downloadable PNGs)
   - **Appendix C** — full dataset CSV download

## Reproducibility

- `config.py:GLOBAL_SEED = 42` seeds Python `random`, NumPy, and TensorFlow.
- Each participant's scenario set is fully determined by their `participant_seed`
  (stored in the database). Re-running `generate_participant_scenarios(seed)` with
  the same seed yields the identical 30 scenarios in the same order.
- Pin package versions by using `requirements.txt` verbatim.

## Feature reference

| Feature               | Type  | Description |
|-----------------------|-------|-------------|
| `trial_index`         | int   | 1–30: position in this participant's randomised order |
| `bias_type`           | int   | 1=framing, 2=anchoring, 3=loss_aversion |
| `frame`               | int   | 0=gain frame, 1=loss frame |
| `expected_value_ratio`| float | EV(on-screen A) / EV(on-screen B) |
| `anchor_value`        | float | Anchor shown; 0 for non-anchoring trials |
| `previous_choice`     | int   | 0/1 — choice on immediately preceding trial |
| `is_first_trial`      | int   | 1 if trial 1 (previous_choice undefined), else 0 |
| `reaction_time_ms`    | int   | ms from scenario display to button click |
| **`choice`**          | int   | **Target**: 0=A, 1=B |
